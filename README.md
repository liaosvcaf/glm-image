# glm-image

OpenClaw skill for generating images from text prompts using the [GLM-Image API](https://open.bigmodel.cn) by Zhipu AI (BigModel).

**Attribution:** Based on [glm-image](https://github.com/ViffyGwaanl/glm-image) by ViffyGwaanl (MIT License).

## Skills

| Skill | Description |
|-------|-------------|
| [glm-image](./glm-image/) | Generate images from text prompts via GLM-Image API |

## Quick Start

1. Get your API key from https://open.bigmodel.cn
2. Set `GLM_API_KEY` in your environment or TOOLS.md
3. Install the skill and ask your agent to generate an image

## Usage

- "Generate an image of a sunset over mountains"
- "Create a picture of a robot playing chess"
- "Draw a futuristic city at night"
