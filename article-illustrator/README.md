# Article Illustrator

Generate beautiful hand-crafted **scrapbook-style** illustrations for any article.

**Attribution:** Based on [glm-image](https://github.com/ViffyGwaanl/glm-image) by ViffyGwaanl (MIT License).

## What It Does

Takes any written article — blog post, essay, newsletter, tutorial, research summary — and produces a set of hand-crafted scrapbook-style images to illustrate it. The final output is the original article in markdown with images inserted at logical points.

## Visual Style

**Physical Mixed-Media Scrapbook** — every image looks like a real handmade collage:

- Torn paper edges with exposed fibers
- Washi tape and binder clips holding elements in place
- Layered backgrounds: watercolor washes, old newspapers, graph paper, circuit textures
- Hand-drawn markers: circles, arrows, radiating lines, stars
- High-saturation color collisions
- Bold sans-serif headlines with thick cut-out borders

## Setup

Requires a GLM API key. See the `glm-image` skill's setup instructions.

## Usage

Provide the article content and ask the agent to illustrate it. Works for any article in any language.

## Output

Complete markdown article with scrapbook-style images inserted at major section breaks.

Typical image count: 2–5 depending on article length.
